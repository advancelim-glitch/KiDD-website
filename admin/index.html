GitHub로 게시 권한 확인

이 페이지는 공개되어 있지만, GitHub 저장소 쓰기 권한이 있는 사용자만 게시할 수 있습니다. 비밀번호 대신 GitHub의 세분화된 개인 액세스 토큰(Fine-grained personal access token)을 사용합니다. 토큰은 이 브라우저 메모리에만 보관하며 서버나 저장소에 저장하지 않습니다. 화면을 닫으면 다시 입력해야 합니다.

토큰은 GitHub 토큰 발급 화면에서 해당 저장소만 선택하고 Repository permissions → Contents → Read and write로 발급하세요. 토큰을 채팅·이메일·다른 사람에게 보내지 마세요.
